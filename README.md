# Portfolio
Welkom in mijn demo portfolio.

Alle bestanden zijn vrij te downloaden
## Skills

### Excel
#### FMWC
Hier heb ik voorbeeldbestanden uit de jaarlijkse Excel E-sports-wedstrijden van de Financial Modeling World Cup (FMWC) gebruikt, deze bestanden zijn gratis te vinden op https://fmworldcup.com/product-category/case-studies/excel-esports-cases/
  Getoonde skills: Diepe en brede kennis van Excel formules (meer dan enkel een XLOOKUP), What-if-Analysis (Data table), hyperlinks, geavanceerde search and replace obv cell format
